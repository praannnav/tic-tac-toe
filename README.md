# Tic‑Tac‑Toe

Live demo: https://praannnav.github.io/tic-tac-toe/

A very simple, client-side 2‑player Tic‑Tac‑Toe game built for the browser. No server — just HTML, CSS and plain JavaScript.

## How to play
1. Open `index.html` in your browser or visit the live demo above.  
2. Player X goes first. Click an empty cell to place X or O.  
3. The game automatically checks for a win or a draw after each move.  
4. Use the Reset button to start a new round.

## Built with
- HTML
- CSS
- JavaScript (vanilla)

## What I learned / what this demonstrates
- Basic CSS for layout and simple styling.  
- Plain JavaScript: event listeners, control flow, and conditional statements.  
- Using a JavaScript object to store game state and player data on the client side.  
- DOM manipulation and simple game logic for a two-player (same device) experience.

## Files
- `index.html` — game UI  
- `style.css` — styles  
- `script.js` — game logic

## Notes
- Local, hotseat (two players on one device).  
- No persistent storage; reloading the page resets the game.  
- Works in modern browsers.
